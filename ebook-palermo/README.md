# E-book «Tutto comincia dalla bocca»

E-book divulgativo di 6 pagine A4, tratto dall'intervento di Maria Francesca Cavaleri
«Educare il microbiota orale: una nuova frontiera nella prevenzione oncologica»
(Corso ECM «Benessere e Salute 2026 – Dall'oncologia all'oncologia integrata», Villa Magnisi, Palermo, 3 ottobre 2026).

- `tutto-comincia-dalla-bocca.pdf`: il PDF pronto da condividere (6 pagine A4 verticali).
- `tutto-comincia-dalla-bocca.html`: il file sorgente modificabile (testo, stili, bibliografia).
- `assets/`: logo Vivibiotic (versione petrolio e bianca), foto dell'autrice, font Barlow (licenza OFL).

## Come modificarlo e rigenerare il PDF

1. Modifica il testo in `tutto-comincia-dalla-bocca.html` (ogni pagina è una `<section class="page">`).
2. Aprilo in Chrome o Chromium: File › Stampa › Salva come PDF, formato A4, margini «Nessuno»,
   con «Grafica di sfondo» attiva.
3. Controlla che il PDF abbia ancora 6 pagine: le pagine hanno altezza fissa, quindi un testo troppo lungo
   viene tagliato in fondo alla pagina invece di passare alla successiva.

I richiami numerati `[n]` nel testo corrispondono all'elenco numerato della pagina 6.
Tutte le fonti sono state verificate su PubMed.
